# oks-page (working name)

A WordPress alternative built with Next.js, Tailwind CSS or custom CSS, and [oks-ui](https://www.npmjs.com/package/oks-ui).

**Status:** milestone M1 (spikes). Nothing is published. The code follows the approved specs.

The research, specifications and decisions live in the documentation repository: [OKS-ORG/CMS-Docs](https://github.com/OKS-ORG/CMS-Docs). Start with its `HANDOFF.md` and `docs/08-m1-plan.md`.

The name `oks-page` is a working name (decision D87). The final name is chosen at the end of M1.
