# oks-page

The site, the admin and the API of oks-page in one package. A project made with `create-oks-page` re-exports its pages from here.

You do not normally install this by hand. To start a site:

```bash
npm create oks-page@beta my-site
```

Needs Node.js 22 or later. More: <https://github.com/OKS-ORG/oks-page#readme>.
