# @oks-page/content-safety

The block checks: every save, import, API call and plugin write is repaired and reported here before it reaches the database.

This is a building block of [oks-page](https://github.com/OKS-ORG/oks-page). Most people do not install it directly: start a site with `npm create oks-page@beta my-site` and it comes along.
